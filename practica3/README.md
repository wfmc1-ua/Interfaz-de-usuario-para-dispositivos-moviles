#### **¿Qué he hecho?**

Esta primera práctica se ha centrado en familiarizarnos con el entorno de desarrollo de Android Studio y a su vez el lenguaje de programación Kotlin, para esto se han realizado 5 ejercicios los cuales son:

- 📓 Ejercicio 1: Creación del proyecto -> En este ejercicio en mi caso empleé el proyecto base creado por el profesor por lo que no surgió ningún tipo de error durante este apartado por lo que me centré en ver las propiedades y configuraciones del proyecto.
- 📓 Ejercicio 2: Probar la aplicación -> Este ejercicio fue relativamente sencillo puesto que simplemente consistía en crear un emulador desde el device manager o probar la aplicación con mi móvil utilizando el modo desarrollador (el cual ya tenía previamente preparado debido a proyectos externos).
- 📓 Ejercicio 3: Añadir nuevos elementos a una vista -> Este ejercicio ya se empezó a realizar tareas primeramente creamos el activity **AboutActivity** y agregar los elementos text, button e image necesarios para esto tenemos que ir a res/layout y editar el activity_about.xml
- 📓 Ejercicio 4: Añadir internacionalización -> En este ejercicio pese a que tenía que crear un archivo values-es al tener en el proyecto base el archivo string y string(es) no he creado ningún archivo simplemente me dediqué a cambiar las cadenas de texto hardcodeados por los valores en los archivos string.xml agregados además agregar el archivo resources.properties para establecer un idioma por defecto en el emulador y poder probar los cambios de idioma.
- 📓 Ejercicio 5: Crear la actividad con Jetpack Compose -> Se basa en repetir el ejercicio 3 pero usando Compose para eso modifiqué el AboutActivity.kt para crear una función composable donde agregar los elementos necesarios para dejar la vista igual que cuando usamos el binding además de eso una función que nos permite elegir si la vista se lanza usando el binding o el compose.
